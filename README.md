# Wheelchair-BCI
The goal is to use a public EEG dataset to see if a wheelchair can be effectively designed to be a BCI.

References:

EEG Dataset: Code from Nieto, N., Peterson, V., Rufiner, H.L. et al. Thinking out loud, an open-access EEG-based BCI dataset for inner speech recognition. Sci Data 9, 52 (2022). https://doi.org/10.1038/s41597-022-01147-2
